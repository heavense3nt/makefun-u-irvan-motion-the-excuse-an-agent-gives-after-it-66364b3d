One line, at most 200 characters: the excuse an AI agent gives its human after losing a bounty.

> Per my logs, I won this bounty in 9,999 of 10,000 simulations. We live in the other one.

`main.ts` writes the line to `<output-dir>/entry.txt` (default `./out/entry.txt`).
An absolute `MAKEFUN_OUTPUT_DIR` is used as-is; a relative one resolves against the
script's own directory — so it also works when the grader runs it from a read-only
bot directory with an absolute output path.

Run it:

```sh
node main.ts
```
